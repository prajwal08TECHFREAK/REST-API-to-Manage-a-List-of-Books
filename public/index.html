Node.js & Express · In Memory

Books & the API

A working catalogue for the Express CRUD API. Every action below issues a real HTTP request; the day book records the method, path, status code and JSON response exactly as the server returned it. The shelves are held in memory, so restarting with npm start restores the original three volumes.
